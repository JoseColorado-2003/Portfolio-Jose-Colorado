03 / Formatos

Distintas formas
de contar.

El formato se elige según el objetivo de comunicación, el producto y la audiencia.

01 / EXPERIENCIA

Testimonio

Una experiencia personal contada de manera cercana y honesta.

02 / DESCUBRIMIENTO

Unboxing

Presentación del producto, empaque y primera impresión.

03 / DEMOSTRACIÓN

Tutorial

Cómo se utiliza el producto y qué características destacan.

04 / NARRATIVA

Voice over

Imágenes de apoyo acompañadas de narración.

05 / SOLUCIÓN

Problema / solución

Una necesidad cotidiana y cómo el producto encaja en ella.

06 / CREATIVIDAD

Storytime / tendencia

Una idea creativa adaptada al lenguaje de las plataformas sociales.
